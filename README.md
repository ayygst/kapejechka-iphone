# Капеєчка для iPhone — локальне зберігання

Операції та власні категорії зберігаються у сховищі цього iPhone. Сервер і акаунт для роботи застосунку не потрібні. Дані не синхронізуються з іншими пристроями. Якщо видалити вебзастосунок або очистити дані Safari, записи можуть зникнути.

## Встановлення

Файли потрібно один раз розмістити на статичному хостингу з HTTPS. Платний DigitalOcean Droplet для цієї версії не потрібен. Після публікації відкрийте адресу в Safari → «Поділитися» → «На початковий екран» → «Додати». Після першого відкриття застосунок зможе запускатися без мережі.

Корінь сайту — ця папка: `index.html`, `sw.js` і папка `static`. Не публікуйте разом із сайтом стару Telegram-базу чи токени.
